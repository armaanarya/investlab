### Task 3: Parquet cache

**Files:**
- Create: `src/investlab/data/cache.py`
- Test: `tests/data/test_cache.py`

**Interfaces:**
- Consumes: `investlab.contracts.Bar`
- Produces:
  - `class SymbolNotCachedError(LookupError)` — message contains `investlab data pull --symbols <SYM>`
  - `class ParquetCache` with `__init__(self, root: Path = Path("data_cache"))`, `write(bars: Iterable[Bar]) -> int`, `read(symbol: str, start: date | None = None, end: date | None = None) -> list[Bar]`, `coverage(symbol: str) -> tuple[date, date] | None`, `symbols() -> list[str]`, `manifest() -> dict`
  - `PULL_COMMAND_HINT: str`

**Design decisions:**
- One parquet file per symbol at `<root>/<safe_symbol>.parquet`, where `safe_symbol` replaces `.` with `_DOT_` so `BRK.B` does not collide with a file extension. Round-trip is exact and tested.
- Prices persist as **strings**, not floats and not parquet decimals: `Decimal("310.339996")` round-trips byte-exact through a string and no scale has to be pinned in advance.
- `write` merges with existing rows, de-duplicates on `session` keeping the newest write, and sorts ascending. Re-pulling a day overwrites it.
- `read` on a symbol with no file raises `SymbolNotCachedError`. It never returns an empty list to mean "not pulled". An empty list means "pulled, but no sessions in that window".
- `manifest()` returns `{"content_hash", "symbol_count", "start", "end", "pulled_at", "symbols"}`. `content_hash` is a sha256 over per-symbol digests of canonical row text — deterministic, independent of file mtime and of write order. `pulled_at` comes from a `_manifest.json` sidecar written by `write`, not from filesystem mtimes.

### Task 4: Price providers

**Files:**
- Create: `src/investlab/data/providers.py`
- Test: `tests/data/test_providers.py`, `tests/data/conftest.py`

**Interfaces:**
- Consumes: `investlab.contracts.{Bar, PriceProvider}`
- Produces:
  - `to_vendor_symbol(s: str) -> str` — `.` → `-`
  - `class YFinanceProvider` — `__init__(self, *, downloader=None, retries=1, price_dp=6)`, `name = "yfinance"`, `available() -> bool`, `fetch(symbols, start, end) -> list[Bar]`
  - `class TiingoProvider` — `__init__(self, *, api_key=None, http_get=None)`, `name = "tiingo"`, reads `TIINGO_API_KEY`, `available()` False without a key
  - `class ChainProvider` + `chain(*providers) -> ChainProvider`
  - `class ProviderError(RuntimeError)`

**Design decisions:**
- Reverse symbol translation uses a request-scoped `{vendor: original}` dict, not a global `-`→`.` rule. `-`→`.` is not invertible in general (real tickers contain hyphens); the dict is exact.
- Retry: after the first `download`, any requested symbol that produced zero rows is re-requested once. A genuinely delisted symbol costs one wasted retry and then yields no bars, which is correct.
- `fetch` never raises for a missing symbol. It catches vendor exceptions per attempt and returns whatever parsed.
- Rounding prices to 6 dp before `Decimal` conversion is safe for `Bar.__post_init__`: round-half-even is monotonic, so `low <= open <= high` cannot invert. Rows with a NaN in any OHLC field are dropped.
- Tiingo uses stdlib `urllib.request` — **do not add a `requests` dependency**, `pyproject.toml` belongs to another agent.
- Tiingo live verification is **pending**: contract tests run against a recorded JSON fixture; the one live test is `@pytest.mark.live` and additionally skips without `TIINGO_API_KEY`.

### Task 5: Indicators

**Files:**
- Create: `src/investlab/features/indicators.py`
- Test: `tests/features/test_indicators.py`

**Interfaces:**
- Consumes: `investlab.contracts.Bar`
- Produces:
  - `frame_from_bars(bars: Sequence[Bar]) -> pd.DataFrame` — the Decimal→float boundary; index `session` (`date`), float64 columns `open/high/low/close/adj_close`, float64 `volume`
  - `sma(values, n) -> pd.Series`
  - `ema(values, n) -> pd.Series` — seeded with the first n-period SMA
  - `macd(values, fast=12, slow=26, signal=9) -> MacdResult(macd, signal, histogram)`
  - `rsi(values, n=14) -> pd.Series` — Wilder
  - `atr(high, low, close, n=14) -> pd.Series` — Wilder, raw OHLC
  - `realized_volatility(close, n=20, periods_per_year=252) -> pd.Series`
  - `breakout_level(high, n=20) -> pd.Series`
  - `relative_volume(volume, n=20) -> pd.Series`
  - `relative_volume_latest(volume, n=20) -> float | None`

**Exact definitions — implement these, do not improvise:**
- `ema`: first valid index is the n-th non-NaN observation; seed = mean of those n; then `e[i] = a*v[i] + (1-a)*e[i-1]`, `a = 2/(n+1)`. Leading NaNs are skipped, not treated as zero — this matters because MACD's signal line is an EMA of a series with 25 leading NaNs.
- `macd`: `macd = ema(v,12) - ema(v,26)`; `signal = ema(macd, 9)`; `histogram = macd - signal`. With SMA seeding, `macd` first valid at index 25 and `signal` at index 33.
- `rsi`: deltas from index 1. Seed `avg_gain`/`avg_loss` = SMA of the first n deltas, first valid at index n. Then `avg = (prev*(n-1) + cur)/n`. Edge cases, declared: both averages 0 → `50.0` (a flat series carries no direction); `avg_loss == 0` → `100.0`; `avg_gain == 0` → `0.0`.
- `atr`: `TR[0] = NaN` (there is no prior close, and fabricating `H-L` pollutes the seed). `TR[i] = max(H-L, |H-C[i-1]|, |L-C[i-1]|)`. Seed = mean of `TR[1..n]`, first valid at index n. Then Wilder.
- `realized_volatility`: simple returns `c[i]/c[i-1]-1`, rolling std `ddof=1` over n returns, `* sqrt(periods_per_year)`. First valid at index n. Callers pass `adj_close`.
- `breakout_level`: `out[i] = max(high[i-n:i])` — **excludes** `high[i]`. NaN for `i < n`.
- `relative_volume`: `out[i] = volume[i] / mean(volume[i-n:i])`. NaN when the denominator is 0 or any window value is missing — never `inf`. `relative_volume_latest` returns a real `None` for the same cases.
- Every function returns a `pd.Series` on the input index, dtype float64, NaN during warm-up.

### Task 7: Cross-sectional ranking

**Files:**
- Create: `src/investlab/features/ranking.py`
- Test: `tests/features/test_ranking.py`

**Interfaces:**
- Produces:
  - `MIN_ELIGIBLE: int = 20`
  - `class MissingPolicy(str, Enum)` — `DROP = "drop"`, `RANK_WORST = "rank_worst"`
  - `@dataclass(frozen=True) class RankResult` — `as_of: date`, `ranks: dict[str, float]`, `dropped: tuple[str, ...]`, `n_eligible: int`, `policy: MissingPolicy`, `ascending: bool`
  - `@dataclass(frozen=True) class InsufficientCoverage` — `as_of: date`, `n_eligible: int`, `required: int`, `detail: str`
  - `percentile_ranks(values, as_of, *, eligible, missing=MissingPolicy.DROP, ascending=False, min_eligible=MIN_ELIGIBLE) -> RankResult | InsufficientCoverage`
  - `cross_section(series_by_symbol: Mapping[str, pd.Series], as_of: date) -> dict[str, float]`

**Design decisions:**
- The eligible set is passed in explicitly. Symbols in `values` but not in `eligible` are ignored silently; symbols in `eligible` but missing from `values` are handled by `missing`.
- Ordinal ranking with ties broken by ascending symbol: sort key is `(-value, symbol)` when `ascending=False`. Percentile = `(N - 1 - i) / (N - 1)`, so best = 1.0 and worst = 0.0. `N >= 20` is guaranteed by the coverage gate, so the denominator is never 0.
- Under `RANK_WORST`, missing symbols are appended after all present ones in ascending symbol order and count toward `n_eligible`.
- Below `min_eligible`, return `InsufficientCoverage` — an explicit marker object, never an exception and never a partial ranking.
