# DECA competition module implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `DecaProfile`, a `CompetitionProfile` implementation that encodes every verified DECA Stock Market Game 2026-27 HS rule — eligibility, sizing, the three-class diversification clock, and end-of-day execution semantics — so the daily order sheet can never silently break a rule.

**Architecture:** One module, `src/investlab/competitions/deca.py`, importing only `investlab.contracts` and the standard library. Module-level constants carry every verified number verbatim. Free functions implement 2026 NYSE business-day arithmetic (no dependency on the CORE agent's `calendar.py`). A frozen dataclass `DecaProfile` holds the two genuinely configurable knobs (unverified SEC fee rate, strategy risk fraction) and implements the protocol. All rule evaluation returns `RuleCheck` objects carrying facts and deadlines, never prose.

**Tech Stack:** Python 3.12, `uv`, pytest, `decimal.Decimal` for all money, `datetime.date` for all sessions.

**Spec:** `docs/superpowers/specs/2026-09-06-investlab-design.md` (sections 3, 5, 8, 10) and the requirements document `docs/rules/deca-verified.md`.

## Global Constraints

- Files owned: **only** `src/investlab/competitions/deca.py` and `tests/competitions/test_deca.py`. Per `docs/superpowers/plans/AGENT-FILE-OWNERSHIP.md`. `contracts.py` is FROZEN — import, never modify.
- Imports permitted: `investlab.contracts` and the standard library. Nothing else. No `portfolio/`, no `data/`, no `features/`, no `wharton.py`.
- Money is `Decimal`. Never `float`. Never construct a `Decimal` from a float literal.
- Share quantities are `int`.
- **AI authorship (spec §3):** the module emits evidence — numbers, dates, constraint names. It never drafts an argument a student would submit. `"position is 31.0% of equity, ceiling is 30.0%"` is correct. `"this position has strong momentum"` is a compliance violation.
- **Unverified means unverified.** Where a rule is not verified, encode it as `RuleStatus.INCOMPLETE` or reject with a reason saying so. Never guess a value, never silently pick one.
- Verified constants, copied verbatim from `docs/rules/deca-verified.md`:
  - Starting cash `Decimal("100000")`; commission `Decimal("5")` per trade, both sides.
  - Margin up to 50% of Total Equity at 7.00%/yr; 0.75%/yr credited on positive cash. `allows_margin = False` by default (spec §5).
  - Shorting allowed by the rules; `allows_shorting = False` in v1 (spec §5).
  - Universe: NYSE + NASDAQ only. Price `>= $3.00` day-before AND day-of. Market cap `>= $25,000,000`. Minimum 10 shares on buys.
  - Position ceiling `20% x 1.5 = 30%` of total equity at purchase.
  - Diversification: `$10,000` net cost in EACH of stocks / mutual funds / bonds by **2026-10-23 16:00 ET**, held through **2026-12-04 16:00 ET**. One business day to restore after a sale.
  - Game window 2026-09-08 09:30 ET to 2026-12-04 16:00 ET.
- Verified-UNVERIFIED items that must surface in output, not be resolved by guessing: the SEC fee rate, NYSE American eligibility, the ~30% maintenance margin (secondary source only).

### Task 4: The diversification engine

**Files:**
- Modify: `src/investlab/competitions/deca.py`
- Test: `tests/competitions/test_deca.py`

**Interfaces:**
- Consumes: Tasks 1-3.
- Produces: `AssetBucket` enum (`STOCKS`, `MUTUAL_FUNDS`, `BONDS`) with `bucket_for(asset_class) -> AssetBucket | None`; `ClassifiedFill` frozen dataclass `(fill: Fill, asset_class: AssetClass)`; `DecaProfile.class_net_cost(account, bucket) -> Decimal`; `DecaProfile.diversification_checks(account, today, sell_history=()) -> list[RuleCheck]`; `REQUIRED_GROSS_OUTLAY: Decimal` (`= DIVERSIFICATION_MINIMUM + COMMISSION_PER_TRADE = Decimal("10005")`).

**The fee arithmetic, stated exactly so it is not re-derived wrongly.** `Lot.net_cost` is `price * quantity` and already excludes commission. DECA measures the $10,000 minimum against that figure and says the $5 fee does not count toward it. So a student who budgets $10,000 of *total outlay* gets $9,995 of net cost and is $5 short. The threshold comparison is `sum(lot.net_cost) >= Decimal("10000")`; the guidance string tells the student the minimum gross outlay is $10,005.00.

**Bucket mapping:** `AssetClass.STOCK` and `AssetClass.ETF` -> `STOCKS` (a bond ETF is a stock). `AssetClass.MUTUAL_FUND` -> `MUTUAL_FUNDS` (a bond mutual fund is a mutual fund). `AssetClass.BOND` -> `BONDS`. `AssetClass.CASH` -> `None`. Only positions with `quantity > 0` count, which is how "only LONG stock positions" is enforced.

**Deadline resolution:** a class that qualifies is satisfied. Otherwise `deadline = max(DIVERSIFICATION_DEADLINE, next_business_day(latest sell session in that bucket))` when a sell exists, else `DIVERSIFICATION_DEADLINE`. The `max` is what makes an early sale fall back to Oct 23 instead of manufacturing a fake one-day clock.
