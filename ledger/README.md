# Ledger

One directory per competition. **They are separate on purpose.** DECA and
Wharton have different capital, different rules, different asset-class
definitions, and deliberately different strategies. A combined book would let a
Wharton position appear to satisfy a DECA requirement, which is the exact
mistake that disqualifies a team.

```
ledger/
  deca/       DECA Stock Market Game    ($100,000, Sept 8 - Dec 4 2026)
  wharton/    Wharton WInS              (capital unconfirmed until Sept 15)
```

## Files in each directory

| File | What it is | Edit by hand? |
|---|---|---|
| `portfolio.json` | Machine state: cash, positions, individual lots. The source of truth. | Only to correct an error |
| `trades.csv` | Append-only log of every recorded fill, oldest first. | No |
| `journal.jsonl` | The student's own reasoning per trade. Hash-chained, append-only. | **Never** |
| `LEDGER.md` | Readable summary. Regenerated on every write. | **Never** — it is overwritten |

## For an agent picking this up cold

Read `LEDGER.md` first. It carries current cash, equity, P&L, open positions,
DECA asset-class totals against the $10,000 diversification minimums, and the
full trade history in one file.

Then know these four things:

1. **Nothing here places trades.** Neither competition has an API. Every order
   is typed into the platform by hand. The platform is the authoritative
   record; this mirrors it.
2. **`investlab fill` is the only writer.** It updates `portfolio.json`,
   appends to `trades.csv`, and regenerates `LEDGER.md` together. Writing one
   without the others leaves the ledger inconsistent.
3. **DECA counts every ETF as a stock**, bond ETFs included. Buying AGG or BND
   does not satisfy the bond requirement. Only bonds SMG itself provides count,
   investment grade at BBB or better.
4. **Never write the journal reasoning.** Wharton's rules state "You may not
   submit any work generated by an AI program as your own," it requires a
   Trading Note per trade, and it audits them: "You must use actual trading
   notes from trades you made on WInS. (Yes, we will verify this.)" The tool
   emits facts and numbers; the student writes the argument.

## Commands

```bash
uv run investlab ledger --profile deca              # current state
uv run investlab ledger --profile deca --refresh    # regenerate LEDGER.md
uv run investlab fill -s AAPL -a buy -q 30 -p 319.97 --profile deca
uv run investlab journal add -s AAPL -a buy -q 30 -p 319.97 --profile deca
```

Use the numbers off the platform's confirmation, not the ones the order sheet
predicted. DECA prices every fill at the session close, so what you were quoted
when you clicked is not what you paid.
